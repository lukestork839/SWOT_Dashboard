Figure 2. Custom Python data-processing pipeline (SWOT_Pull.py) that converts raw satellite measurements into the analysis-ready products used throughout this thesis, read top to bottom. Box colour encodes the processing stage — data source (blue), per-pass processing (white), quality-control filters (orange), the daily checkpoint (yellow), aggregation (purple), data products (green), and downstream uses (grey) — and is deliberately kept distinct from the red/blue river palette used in the other figures. Beginning from NASA's Surface Water and Ocean Topography (SWOT) pixel-cloud product, each satellite pass is processed independently: the granule is ingested, spatially clipped to the two channel polygons, converted to true water-surface elevation, and assigned an along-stream distance measured from the common anchor point (Figure 1). Four quality-control filters, applied in the order shown, then remove unreliable measurements before each pass is written to a dated checkpoint file that makes the pipeline resumable. Aggregation combines all passes into the master dataset, excluding documented bad passes, and derives the per-pass reference hydraulic gradient. These two data products feed the three consumers of the pipeline: the temporal-stability analysis (Figure 3), the interactive dashboard, and the static thesis figures (Figures 1 and 3-8). Each step is described in detail in Section 4.2.
