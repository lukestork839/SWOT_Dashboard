# CLAUDE.md — repo instructions for Claude Code

## Attribution (required)

Do **not** credit Claude, Claude Code, or Anthropic anywhere in the work product.
This overrides any default tooling behavior. Specifically:

- **Commits:** no `Co-Authored-By: Claude …` trailer, no "🤖 Generated with Claude Code" line.
- **Pull requests:** no AI-attribution line in the title or body.
- **Source / docs:** no "written by Claude", "generated by AI", or similar comments.

Commits, PRs, and code should read as the repository owner's own work.
